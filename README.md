# protobuf-go

A fork of [Go protocol buffers](https://github.com/protocolbuffers/protobuf-go)
(`google.golang.org/protobuf`) at v1.36.11, cut down to the runtime that
generated code needs and kept free of dependencies.

- **Module:** `github.com/raftseg/protobuf-go`.
- **Upstream's code, all but unchanged:** every file is upstream's, with
  import paths rewritten to this module, and one fix (FORK.md lists it).
  `internal/tools/prune` writes the whole tree from an upstream checkout,
  and CI checks that running it again changes nothing.
- **Only what is needed:** the 33 packages (about 44,000 lines) that the
  runtime (`proto`, `protoreflect`, `protoregistry`, `protowire`,
  `protoiface`, `protoimpl`) and protoc plugins (`prototext`, `protodesc`,
  `descriptorpb`, `dynamicpb`, `gofeaturespb`, `pluginpb`) need. Of the
  rest of upstream, only what their tests import is kept, without its own
  tests.
- **No dependencies:** `go.mod` requires nothing, and every package, tests
  included, imports only the Go standard library and this module.
  `internal/depcheck` fails the tests otherwise. go-cmp, the one third-party
  module upstream's tests use, is copied into `internal/gocmp`.
- **Compatible with etcd raft's latest release:** CI builds etcd raft
  v3.7.0 with its protobuf imports pointed at this fork and runs its tests.

[FORK.md](FORK.md) lists what was kept, what was left out and why, and how
to follow an upstream release. Upstream's README is
[UPSTREAM-README.md](UPSTREAM-README.md). The license is upstream's, BSD
3-Clause ([LICENSE](LICENSE)), with Google's patent grant
([PATENTS](PATENTS)); [NOTICE](NOTICE) lists what this fork changed.

## Using it

Code generated by `protoc-gen-go` imports `google.golang.org/protobuf`.
To build it against this fork, rewrite those imports to
`github.com/raftseg/protobuf-go`, as CI does for etcd raft. Messages built
on this fork are not `proto.Message` values of `google.golang.org/protobuf`,
and the two keep separate registries, so one program can link both without
conflict but cannot pass messages between them.

## Testing

```
go test ./...
go test -short -race ./...
go test -tags=protolegacy ./...
go test -tags=protoreflect ./...
go test ./proto -test_lazy_unmarshal
GOARCH=386 go test ./...
```

These are upstream's own test runs (its `integration_test.go`), apart
from the conformance suite and the check of generated files: both need
the C++ protobuf repository built with Bazel, and are left to upstream.
